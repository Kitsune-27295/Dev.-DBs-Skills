## Notes on nuances across sources

- **Circuit Breakers vs. Token-Bucket Retry Throttling:** Azure Architecture Center (Source 1) recommends the classic 3-state Circuit Breaker for sustained dependency outages, while Marc Brooker / AWS Builders' Library (Source 4) notes that circuit breakers introduce modal state transitions that can be hard to test and recover smoothly, favoring local **token-bucket retry throttling** in AWS SDKs alongside per-layer single-point retries. Both agree that unthrottled retries against an overloaded service make outages worse; choose Circuit Breakers when fast-fail + explicit fallback degradation is needed, and cap retry budgets either way.
- **Log severity during retries:** Azure Retry guidance (Source 2) specifically advises logging early transient retry failures at informational level and only the exhausted final attempt as an error so operators are not flooded with alerts for self-healing blips.
