## Notes on disagreements and nuances across sources

- **Static Viewer vs. Full Build Pipeline for API Specs:** Source 4 notes that many teams stop after rendering a static HTML viewer from `openapi.yaml` or `asyncapi.yaml`, which still forces consumers to hand-write serialization and retry code and allows specs to rot unless validated in CI. Validating specs in CI and generating typed SDKs/contracts keeps the documentation, server, and clients locked in sync.
